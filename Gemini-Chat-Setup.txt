RYKAAR GEMINI CHAT

LOCAL SITE
1. Open Open-Rykaar-Site-Locally.cmd.
2. Sign in to Admin CMS and open the Gemini Chat tab.
3. Create a Gemini API key in Google AI Studio, paste it into the API key field, and choose Save & Connect Gemini.
4. Adjust the chat title, welcome message, model, and assistant instructions as needed.

The API key is held by the local server in memory. It is not saved in the HTML or browser storage. If the server closes or restarts, enter the key again. The local chat is available on this computer only.

PUBLIC WEBSITE
For visitors on other devices to use chat, deploy the site with a backend server and set GEMINI_API_KEY and RYKAAR_ADMIN_PASSCODE as server environment variables. Do not put a Gemini key in the HTML or publish it in a client-side script. The local launcher binds only to this computer and is not public hosting.
